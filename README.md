  <h1 align="center">Tailscale OS</h1>
  <p align="center">A modern OS for Tailscale.</p>

---

**Tailscale OS** is a modern OS for running Tailscale: secure, immutable, and minimal.
Tailscale OS is fully open source.
All system management is done via an API - there is no shell or interactive console.
